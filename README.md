# Simple MVC PySide6 Temperature Converter

## Description

This is a simple desktop GUI application built with Python, PySide6, and Qt Designer. The app allows the user to enter a Fahrenheit temperature and convert it to Celsius.

## MVC Overview

- Model: Handles the temperature conversion logic and input validation.
- View: The GUI created in Qt Designer using `view.ui`.
- Controller: Connects button clicks to the model and updates the view.
